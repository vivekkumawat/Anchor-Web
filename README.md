# Anchor: website and privacy policy

The public pages for Anchor, the new-tab extension for Chrome and Brave, served by GitHub Pages:

- Home: https://vivekkumawat.github.io/Anchor-Web/
- Privacy policy (the URL for the Chrome Web Store's Privacy tab): https://vivekkumawat.github.io/Anchor-Web/privacy.html

Questions, bug reports and feature requests: [open an issue](https://github.com/vivekkumawat/Anchor-Web/issues).

The extension's source code lives in a separate private repository.
